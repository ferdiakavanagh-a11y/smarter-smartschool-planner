# Changelog

## 3.0.0

- Replace the HTML/WebView desktop shell with the native Qt Quick planner.
- Add liquid glass controls, animated sync feedback and original adaptive wallpapers.
- Default new installations to Clear Light with Soft colours; retain saved preferences.
- Preserve the visible reading position for Completed, pins, notes and Undo.
- Improve task, schedule, grade and LVS presentation, keyboard access and text scaling.
- Fix Smartschool account identity parsing after homepage bootstrap changes.
- Harden cache validation, durable saves, redirects and locked release dependencies.
- Remove retired HTML renderer assets and obsolete local executable/build outputs.

Known startup limitations: skipping launch after a manual upgrade can omit patch
notes; upgrading clears an unfinished first rendering choice. These remain unchanged.
Installer publication and automatic installation remain subject to approved signing.
